# 📈 Reliance Stock Price Forecasting using LSTM

An end-to-end deep learning project that forecasts the **next-day closing price of Reliance stock** using a stacked **LSTM (Long Short-Term Memory)** neural network. The project covers the full pipeline — data loading, preprocessing, sequence generation, model building, training, evaluation, visualization, and next-day prediction — with detailed console output at every step for learning purposes.

---

## 🎯 Project Objective

To build a time-series forecasting model that learns historical patterns from Reliance stock Close prices and predicts the next day's closing price with reasonable accuracy.

---

## 🧠 Concepts Covered

- Time Series Forecasting
- Min-Max Scaling & Inverse Scaling
- Sliding Window Sequence Generation
- LSTM Architecture (Forget / Input / Output Gates, Cell State)
- Backpropagation Through Time (BPTT)
- Early Stopping to prevent Overfitting
- Regression Evaluation Metrics (MAE, MSE, RMSE)
- Data Visualization with Matplotlib
